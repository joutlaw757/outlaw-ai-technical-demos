# AI Governance Model Audit (new illustrative sample)

Self-contained synthetic classification demo that trains a logistic regression model, prints classification metrics and a simple subgroup false-positive-rate comparison. This is a **new demonstration**, not a reproduction of the author's Ph.D. experiments and not a validated fairness or legal-risk assessment. Synthetic labels are not real criminal justice outcomes.

## Run
```bash
python -m venv .venv
# activate environment
pip install -r requirements.txt
python audit.py
```

The dataset and subgroup attributes are synthetic; results are for software demonstration only.
